# lobehub-skills-export

导出镜像（export-only），**唯一真值源是 https://github.com/huhoo/cue-awesome**。

- 本仓内容全部由主仓构建口从 `cue-awesome 37d994d` 生成，按渠道导入器要求的 `skills/<名>/SKILL.md` 布局摆放；本仓**不手改**、不接受独立改动，改进一律回主仓走门禁后重导。
- 收录范围：仅已验收且已出门的件。当前 pilot 一枚：`skills/long-doc-translation`。
- 出处与许可见 `LICENSE.md` 与 `NOTICE.md`（随主仓同源同版）。
- 每个技能包内自带机检、随包自测入口与面文承诺；安装与使用请以主仓 README 为准。
